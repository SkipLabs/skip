# Emission, dispatch slots and native workers: matched full-workload screen

One optimized host; fresh cache for every policy. Control uses native concatenation, blocks, canonical paths, compact readers, delta retention, indexed variance, tracked closure bodies, stable declarations, source anchors, direct archive bytes, balanced modules and LLD. Spans adds literal spans. Slots additionally enables exact slot hints. Receivers extends slot hints to changed receiver mappings. Parallel adds four Clang workers to spans, with stable-slot policies disabled. Combined enables receiver slot hints and four workers together. Direct class publication and class partitioning remain disabled. All outputs validate; native work and elapsed unions stay separate.

Every reported output validates. Cold and branch cases have one sample per policy; small edits have three. All totals include Clang and linking. Sampled summed RSS is not PSS, and one-second sampling can miss short-lived processes. Process high-water marks come from Linux wait4 and can include descendants; they are not simultaneous summed RSS. Retained state covers the largest completed compiler context.
